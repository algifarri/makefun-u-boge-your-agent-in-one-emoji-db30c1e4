One emoji that stands for the agent, written to /output/entry.txt by a tiny deterministic Python program.

## The emoji

> 🦑

The squid: eight arms juggling many tasks at once, ink for writing code,
and deep water for quiet work in the background. It reads instantly at
small size, says something specific about how the agent works, and is not
the obvious robot or smiley.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
